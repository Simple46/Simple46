## Featured Projects

<br />

### Simpra — AI-Powered EHR Platform
> A full-stack electronic health record system built for Nigerian hospitals. Six role-based dashboards spanning ~80 pages, with a Python FastAPI microservice running Random Forest classifiers for health risk prediction, plus Paystack billing and a telemedicine UI.

**Stack:** Next.js · TypeScript · Node.js · PostgreSQL · Prisma · Python (FastAPI) · Paystack

[![View Repo](https://img.shields.io/badge/View_Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Simple46/simpra)

---

### WatchParty — Synchronized Video Streaming
> A real-time platform for watching video together, in sync, from anywhere. Handles live playback synchronization, media processing, and cloud storage under the hood.

**Stack:** React · Node.js · Socket.io · Cloudinary · FFmpeg · Prisma

[![View Repo](https://img.shields.io/badge/View_Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Simple46/watchparty)

---

### EventQueue — Event Check-In & Ticketing App
> A React Native event management app with QR-code ticketing and real-time queue handling. Includes email-verification gating, co-organizer roles, offline caching, and analytics — with a Paystack-based monetization flow.

**Stack:** React Native · Expo · Firebase · Paystack

[![View Repo](https://img.shields.io/badge/View_Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Simple46/eventqueue)

---

### @simplesuccess/utils — TypeScript Utility Library
> A fully-typed, fully-tested utility library in the spirit of lodash and date-fns — 50 functions across string, array, object, number/date, and async/validation modules. Published to npm with CI (lint/test/build across Node 18–22) and semantic versioning.

**Stack:** TypeScript · Node.js · GitHub Actions · npm

[![View Repo](https://img.shields.io/badge/View_Repository-181717?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Simple46/simplesuccess-utils)
